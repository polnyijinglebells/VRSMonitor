VRS MONITOR — БЫСТРЫЙ ЗАПУСК
============================

1. Распакуйте ВЕСЬ архив в отдельную папку на Windows Server.

2. В Virtual Radar Server установите и включите официальный плагин WebAdmin.
   В Tools -> Options -> Web Server создайте пользователя и отметьте его
   администратором в разделе Administrators.

3. Откройте config.json в Блокноте и проверьте строки vrs_url,
   vrs_username и vrs_password.
   Примеры:
     http://127.0.0.1:8080/VirtualRadar
     http://127.0.0.1:8888/VirtualRadar

   Если VRS установлен на другом компьютере, вместо 127.0.0.1 укажите его IP-адрес.
   Эти же логин и пароль можно указать позднее в настройках веб-панели.

4. Запустите start.bat или VRSMonitor.exe.

5. На самом сервере откройте:
     http://127.0.0.1:8090

   С другого компьютера локальной сети:
     http://IP-АДРЕС-СЕРВЕРА:8090

6. Если приёмники не появились, запустите check-server.ps1 правой кнопкой
   мыши через PowerShell. Скрипт покажет, доступен ли адрес VRS.

7. Не переносите старую папку data при новой установке. При обновлении существующего
   сервера сохраните папку data и config.json — в них находятся история и настройки.

АВТОЗАПУСК
----------
Для постоянной работы нажмите правой кнопкой по PowerShell,
выберите «Запуск от имени администратора», перейдите в папку приложения
и выполните:

  Set-ExecutionPolicy -Scope Process Bypass
  .\install-service.ps1

Скрипт также разрешит порт панели в брандмауэре только для локальной сети.
Чтобы не менять брандмауэр, запустите: .\install-service.ps1 -SkipFirewall

УВЕДОМЛЕНИЯ
-----------
Откройте «Настройки» в веб-панели и внесите Telegram Bot Token и Chat ID
или адрес webhook. Настройки сохраняются в config.json.

ДАННЫЕ
------
История и журнал автоматически создаются в подпапке data рядом с программой.
Общий и суточный счётчики сохраняются в data\vrs_monitor.db и не пропадают
при закрытии браузера, перезапуске монитора или Virtual Radar Server.
Логин и пароль VRS WebAdmin сохраняются в config.json.
Не запускайте одновременно две копии VRSMonitor.exe из одной папки.
